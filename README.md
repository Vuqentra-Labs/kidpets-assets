# KidPets

KidPets is a Minecraft Pet plugin where every Pet offers a unique role, progression path and set of abilities.

Pets are not only cosmetic companions. Each one changes how the player explores, survives, gathers resources or fights.

> **Project status:** In development.

## Highlights

- Every Pet has a unique gameplay identity
- No duplicated abilities between Pets
- Individual Pet progression
- Action-based evolution requirements
- Passive, active and ultimate abilities
- Expandable documentation and configuration structure
- Designed for RPG, Survival and progression-focused servers

## Pet Ability Structure

Every Pet has four qualities:

1. **Action Passive**  
   Triggered while the player performs an action related to the Pet.

2. **Need Passive**  
   Triggered automatically when the player needs assistance.

3. **Active Ability**  
   Manually activated by the player.

4. **Ultimate Ability**  
   A powerful ability with a longer cooldown or charging requirement.

[Read the complete Pet System documentation](docs/en/pet-system.md)
