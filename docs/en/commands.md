# Commands

> Replace the example commands below with the commands implemented by the plugin.

## Player Commands

| Command | Permission | Description |
|---|---|---|
| `/pet` | `yourplugin.pet` | Opens the main Pet menu |
| `/pet help` | `yourplugin.pet.help` | Shows available commands |
| `/pet select` | `yourplugin.pet.select` | Selects an available Pet |
| `/pet status` | `yourplugin.pet.status` | Shows information about the active Pet |
| `/pet ability` | `yourplugin.pet.ability` | Uses the active ability |
| `/pet ultimate` | `yourplugin.pet.ultimate` | Uses the ultimate ability |

## Administrative Commands

| Command | Permission | Description |
|---|---|---|
| `/petadmin give` | `yourplugin.admin.give` | Gives a Pet to a player |
| `/petadmin remove` | `yourplugin.admin.remove` | Removes a Pet from a player |
| `/petadmin level` | `yourplugin.admin.level` | Changes a Pet level |
| `/petadmin reload` | `yourplugin.admin.reload` | Reloads supported configuration files |
