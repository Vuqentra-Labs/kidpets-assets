# Installation

## Requirements

- A compatible Minecraft server implementation
- The Java version required by the plugin build
- The latest compatible version of KidPets

## Steps

1. Stop the Minecraft server.
2. Place the plugin `.jar` file inside the server's `plugins` folder.
3. Start the server.
4. Review the generated configuration files.
5. Configure permissions for players and administrators.
6. Restart or reload only when supported by the plugin.

## Verification

After installation, use:

```text
/pet help
```

Confirm that the main Pet command is available and that no errors appear in the server console.

## Updating

1. Back up the plugin folder and server data.
2. Stop the server.
3. Replace the old `.jar` file.
4. Start the server.
5. Review the changelog and configuration changes.
