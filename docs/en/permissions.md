# Permissions

> Replace these example permission nodes with the final plugin permissions.

| Permission | Default | Description |
|---|---|---|
| `yourplugin.pet` | true | Access to the main Pet command |
| `yourplugin.pet.help` | true | Access to the help command |
| `yourplugin.pet.select` | true | Allows Pet selection |
| `yourplugin.pet.status` | true | Allows viewing Pet status |
| `yourplugin.pet.ability` | true | Allows active ability usage |
| `yourplugin.pet.ultimate` | true | Allows ultimate ability usage |
| `yourplugin.admin.*` | op | Grants all administrative permissions |
