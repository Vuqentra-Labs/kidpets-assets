# Comandos

> Substitua os comandos de exemplo abaixo pelos comandos implementados no plugin.

## Comandos de Jogador

| Comando | Permissão | Descrição |
|---|---|---|
| `/pet` | `yourplugin.pet` | Abre o menu principal dos Pets |
| `/pet help` | `yourplugin.pet.help` | Exibe os comandos disponíveis |
| `/pet select` | `yourplugin.pet.select` | Seleciona um Pet disponível |
| `/pet status` | `yourplugin.pet.status` | Exibe informações do Pet ativo |
| `/pet ability` | `yourplugin.pet.ability` | Utiliza a habilidade ativa |
| `/pet ultimate` | `yourplugin.pet.ultimate` | Utiliza a Super Habilidade |

## Comandos Administrativos

| Comando | Permissão | Descrição |
|---|---|---|
| `/petadmin give` | `yourplugin.admin.give` | Entrega um Pet ao jogador |
| `/petadmin remove` | `yourplugin.admin.remove` | Remove um Pet do jogador |
| `/petadmin level` | `yourplugin.admin.level` | Altera o nível de um Pet |
| `/petadmin reload` | `yourplugin.admin.reload` | Recarrega arquivos de configuração suportados |
