# Instalação

## Requisitos

- Uma implementação compatível de servidor Minecraft
- A versão Java exigida pela build do plugin
- A versão compatível mais recente do KidPets

## Passos

1. Pare o servidor Minecraft.
2. Coloque o arquivo `.jar` do plugin dentro da pasta `plugins`.
3. Inicie o servidor.
4. Revise os arquivos de configuração gerados.
5. Configure as permissões dos jogadores e administradores.
6. Reinicie ou recarregue somente quando o plugin oferecer suporte.

## Verificação

Após a instalação, utilize:

```text
/pet help
```

Confirme que o comando principal está disponível e que nenhum erro aparece no console.

## Atualização

1. Faça backup da pasta do plugin e dos dados do servidor.
2. Pare o servidor.
3. Substitua o arquivo `.jar` antigo.
4. Inicie o servidor.
5. Revise o changelog e possíveis alterações de configuração.
