# Permissões

> Substitua as permissões de exemplo pelas permissões finais do plugin.

| Permissão | Padrão | Descrição |
|---|---|---|
| `yourplugin.pet` | true | Acesso ao comando principal |
| `yourplugin.pet.help` | true | Acesso ao comando de ajuda |
| `yourplugin.pet.select` | true | Permite selecionar Pets |
| `yourplugin.pet.status` | true | Permite visualizar o status do Pet |
| `yourplugin.pet.ability` | true | Permite usar a habilidade ativa |
| `yourplugin.pet.ultimate` | true | Permite usar a Super Habilidade |
| `yourplugin.admin.*` | op | Concede todas as permissões administrativas |
